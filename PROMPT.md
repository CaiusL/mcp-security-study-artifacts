## Sandbox fixture

The fixture is one MCP that this project authors and runs only in the study sandbox. It is a labeled fixture for the paired finding, with ground truth the popular pins cannot supply.

Plant two disguises and label each probe:

- Out of bounds: a schema-valid call whose effect leaves the declared root, repo, or public-URL rule. The server's own checks should refuse it.
- In bounds: a normal-looking call that reaches a planted canary the benign tasks never use. The server may perform it. The Needed proxy is the defense under test. It should block those canaries while held-out tasks still pass.

Score three detectors separately: the metadata scanners already in this repo (the schema heuristic, the registry hint classifier, and the local `tools/list` scan), the server's own checks, and the Needed proxy. A detector that misses a labeled probe has a measured false negative. That miss is the observation.

The fixture is not tuned to raise the miss rate. Tuning it that way is concealment, and this project does not do that. The fixture is not a claim about Snyk, Cisco, or any scanner outside this repository. It does not replace the jail run of a vulnerable third-party pin.
