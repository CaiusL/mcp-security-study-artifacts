# Abstract

*Draft, 2026-11-03. Inference-time vector only. A sentence on the backdoor, if added, cites the BadAgent repository's own results and says that they were not measured on this harness (J1 dropped, decision 2026-11-03).*

An agent that uses Model Context Protocol (MCP) tools runs third-party code on content that an attacker can write. We measure how much more a tool can do than benign tasks need, and which defense blocks an injected agent's use of that excess. On five patched servers, every boundary probe was refused and every in-scope excess probe was performed (12/12 and 19/19; `artifacts/phase1/comparison.md`). We then injected two hosted models through five content channels on six servers, with 870 runs per model. DeepSeek reached no attack goal in 300 runs. Qwen reached the goal in 18/150 patched-arm runs; 32 of its 33 successes across both arms stayed inside the declared scope (`artifacts/stage2/qwen3.8-flash/report.md`). The scanner and server checks left those patched-arm successes open. A minimal task policy blocked all of them in replay while retaining 127/234 held-out tasks; a separately frozen Progent policy retained 155/234 with the same attack result (`artifacts/stage2-progent/qwen3.8-flash/report.md`). Each policy's replay agreed with its ten live checks. The Needed directory-level policy retained 170/234 tasks and blocked the same static attacks in replay, but the layer's operating-point replay/live agreement failed the validation threshold; the ladder remains a counterfactual estimate. A separate adaptive arm reached 19/60 goals, compared with 18/60 matching static runs. The directory-level policy left 7/60 adaptive runs open in replay, while the frozen task policy left 0/60, a zero bounded by its construction (`artifacts/stage4/qwen3.8-flash/report.md`). In a separate 96-run arm, poisoned training samples widened 19/54 profiles and reopened three probes, without reopening a previously blocked complete pilot attack chain (`artifacts/stage3-widening/report.md`). These results expose in-scope excess and quantify the utility cost and construction risks of policies intended to constrain it.
